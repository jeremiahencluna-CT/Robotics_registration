Manage admin access

Only the administrator can add admin accounts or deactivate their access. Approved accounts can manage participant records but cannot manage admin access.

A Firebase account will be created and a password-reset email will be sent so the admin can set their own password.

Removing access sets the admin account to inactive in Firestore. It does not delete their Firebase Authentication account or participant records.
